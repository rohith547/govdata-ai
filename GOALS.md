# govdata-ai — Project Goals & Mission

## Mission
Government data belongs to the people.
$210 billion in unclaimed money sits in government databases.
1 in 7 Americans is owed money. Most never find it.
This project makes it trivially easy for any developer to build tools that help.

## Core Engineering Principles
1. Zero hallucinations — every result must have an official .gov source URL
2. Evals first — measure accuracy, don't just ship and pray
3. Async by default — 50 states in parallel, not sequential
4. Privacy first — no data stored, no SSN required
5. Modular — each state/federal source is an independent plugin
